WildCard 从 2022 年前后开始，是中文用户圈子里知名度最高的虚拟信用卡平台之一，主要围绕 ChatGPT、Apple ID、Netflix 这类海外订阅场景，靠低门槛开户和支付宝充值积累了大批用户。

## 续订机制：不用每月重新下单，但有一个前提

前面提到的公开记录显示，第二个月的续订确实做到了“无感”——没有新订单，没有二次付款，Plus 正常续上。

但这个自动化有一个前提：平台手里还握着能登录你账号的有效 Session。Session 不是永久凭证，有效期结束、你重新登录、账号登出或登录状态变化，都可能让原来的 Session 失效。一旦失效，平台没法再自动进你的账号，就会提示你重新上传。

重新上传这件事本身很轻：不产生新订单，不需要再付一分钱，按第一次的流程复制粘贴一遍 Session 就行。订单和剩余月份不会因为重传而消失。已完成的订单会保持原样——订阅类型、时长、金额、状态都还在。

还有个容易误会的点：上传成功只代表平台收到了新的有效登录态，不代表下一期已经提前续上。真正的验证要等到续费节点过后，看 WildAI 的订阅页、ChatGPT 的 Plus 状态和新的到期时间。

### 三种情况分别怎么处理

**情况一：Plus 确实过期了。** 比如账号显示 Free、续费节点过后 Plus 没恢复。这时按客服给出的通用流程走：登录 ChatGPT 查有没有逾期账单 → 进设置和账单页取消当前方案 → 重新登录让账号回到 Free → 回到 WildAI 的交易记录页 → 点 Fix Subscription → 重新提交有效的 Session。

**情况二：Plus 一切正常。** 账号还显示 Plus、没有逾期账单、功能都能用。那就不用反复点了，弹窗选“稍后”或者直接关掉。客服最后也明确说了：不需要再点。

**情况三：拿不准。** 把这些页面都截图——弹窗、WildAI 订单页、ChatGPT 当前方案页、账单明细、当前订阅周期和到期时间——一起发给客服。比起只说“弹窗一直出现”，完整的状态截图能让客服直接判断该走哪套流程。

还有一条提醒：别因为客服第一轮发来的是通用处理方案，就把一个正常的方案直接取消掉。取消这个动作会真实改变你的订阅状态，原本没事的订阅可能反而被自己搞出事来。

- Session 只提交到 WildAI 官方页面的上传窗口，不公开发布，不发给别人；
